१७. Advanced Functions

*args

Function मा कति वटा positional arguments आउने हो निश्चित नभए *args प्रयोग गर्न सकिन्छ। 

def total(*numbers):

    result = 0

    for number in numbers:
        result += number

    return result

print(total(10, 20, 30, 40))

**kwargs

धेरै keyword arguments लिन **kwargs प्रयोग गर्न सकिन्छ। 

def profile(**data):

    for key, value in data.items():
        print(key, value)

profile(
    name="Roshan",
    age=19,
    course="Python"
)

Lambda Function

सानो function लाई छोटकरीमा लेख्न lambda उपयोगी हुन्छ। 

square = lambda x: x * x

print(square(5))

Recursion

Function ले आफैंलाई call गर्ने प्रक्रियालाई recursion भनिन्छ। यसमा stopping condition अर्थात् base case हुनु आवश्यक हुन्छ। 

def countdown(n):

    if n <= 0:
        return

    print(n)

    countdown(n - 1)

countdown(5)

२१. Exception Handling

Program चलाउँदा गलत input वा अन्य runtime समस्या आउन सक्छ। त्यस्ता समस्या व्यवस्थित रूपमा handle गर्न exception handling प्रयोग गरिन्छ।

try:

    print("Program running")

except Exception:

    print("Something went wrong")

else:

    print("No error occurred")

finally:

    print("Program finished")

२६. Inheritance

एउटा class का properties र methods अर्को class ले प्रयोग गर्न सक्ने concept लाई inheritance भनिन्छ। 

class Animal:

    def speak(self):
        print("Animal sound")


class Dog(Animal):

    def bark(self):
        print("Woof!")


dog = Dog()

dog.speak()
dog.bark()

यहाँ Dog class ले Animal बाट speak() method प्राप्त गरेको छ।

२७. Polymorphism

एउटै method name फरक class मा फरक तरिकाले काम गर्न सक्ने concept लाई polymorphism भनिन्छ। 

class Dog:

    def sound(self):
        print("Dog barks")


class Cat:

    def sound(self):
        print("Cat meows")


animals = [
    Dog(),
    Cat()
]

for animal in animals:
    animal.sound()

दुवै object मा sound() method छ तर output फरक हुन्छ।

३३. Practical Python Projects

अब सिकेका concepts प्रयोग गरेर केही साना projects बनाऔँ। यी project हरू अभ्यासका लागि हुन्।

Project 1 — Calculator

def calculator():

    a = float(input("Enter first number: "))
    operator = input("Enter operator (+ - * /): ")
    b = float(input("Enter second number: "))

    if operator == "+":
        result = a + b

    elif operator == "-":
        result = a - b

    elif operator == "*":
        result = a * b

    elif operator == "/":

        if b == 0:
            print("Cannot divide by zero.")
            return

        result = a / b

    else:
        print("Invalid operator.")
        return

    print("Result:", result)

Project 5 — Simple Banking Program

balance = 1000

while True:

    print("\n1. Check Balance")
    print("2. Deposit")
    print("3. Withdraw")
    print("4. Exit")

    choice = input("Choose: ")

    if choice == "1":

        print("Balance:", balance)

    elif choice == "2":

        amount = float(
            input("Enter deposit amount: ")
        )

        if amount > 0:

            balance += amount

            print("Deposit successful.")

        else:

            print("Invalid amount.")

    elif choice == "3":

        amount = float(
            input("Enter withdrawal amount: ")
        )

        if amount <= 0:

            print("Invalid amount.")

        elif amount > balance:

            print("Insufficient balance.")

        else:

            balance -= amount

            print("Withdrawal successful.")

    elif choice == "4":

        break

    else:

        print("Invalid option.")
