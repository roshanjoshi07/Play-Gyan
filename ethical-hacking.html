📚 Ethical Hacking Basics

Ethical Hacker भनेको के हो?

अनुमति लिएर computer system, website वा network मा security कमजोरी पत्ता लगाउने cybersecurity professional लाई ethical hacker भनिन्छ।

🔄 सामान्य Security Methodology

  1. Scope र permission निर्धारण
  2. Information gathering
  3. Security weaknesses पहिचान
  4. Controlled testing
  5. Evidence/documentation
  6. Fix र remediation
  7. Final security report

कुनै website, account, Wi-Fi वा device मा owner को स्पष्ट अनुमति बिना security testing गर्नु हुँदैन।

📡 Wi-Fi Security

Wi-Fi security मा मुख्य कुरा

  • WPA3 प्रयोग गर्नु राम्रो हुन्छ।
  • WPA2-AES पनि supported devices मा सुरक्षित विकल्प हो।
  • Router administrator password परिवर्तन गर्नुहोस्।
  • WPS आवश्यक नभए disable गर्न सकिन्छ।
  • Router firmware update राख्नुहोस्।
  • Guest network प्रयोग गर्न सकिन्छ।

WPA2 vs WPA3

WPA3

नयाँ security improvements सहितको Wi-Fi protection standard।

🌐 Web Security

SQL Injection के हो?

Application ले user input लाई सुरक्षित रूपमा handle नगर्दा database query मा unintended behavior हुन सक्ने vulnerability हो।

🛡️ बच्ने तरिका

  • Parameterized queries प्रयोग गर्ने
  • Input validation गर्ने
  • Least-privilege database accounts प्रयोग गर्ने
  • Errors मा sensitive database information नदेखाउने

🧪 XSS Concept

Cross-Site Scripting (XSS) मा unsafe user input browser मा executable content का रूपमा प्रस्तुत हुन सक्छ।

Safe practice: User Input → Validation → Sanitization → Safe Output

🛡️ Protection

  • Output encoding
  • Input validation
  • Content Security Policy
  • Safe DOM APIs

🔒 HTTPS

HTTPS ले browser र server बीचको communication लाई TLS मार्फत सुरक्षित बनाउँछ।

🔑 Password Security

सुरक्षित password लामो, unique र अनुमान गर्न कठिन हुनुपर्छ। एउटै password धेरै ठाउँमा प्रयोग नगर्नु राम्रो हुन्छ।

🧂 Hashing Concept

Password लाई database मा plain text रूपमा राख्नु हुँदैन। व्यवहारिक systems मा password hashing का लागि Argon2id, bcrypt जस्ता purpose-built algorithms प्रयोग गरिन्छ।

Password ↓ Password Hashing Algorithm ↓ Salt + Hash ↓ Database

🖥️ Network Security Basics

VPN
