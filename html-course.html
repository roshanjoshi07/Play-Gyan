1. HTML के हो?

HTML को पूरा नाम HyperText Markup Language हो। HTML को प्रयोग website को structure बनाउन गरिन्छ।

सरल भाषामा: HTML ले website मा heading, paragraph, image, button, link र अन्य content कहाँ राख्ने भनेर structure तयार गर्छ।

2. HTML Document Structure

हरेक HTML webpage को एउटा आधारभूत structure हुन्छ।

Example
<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <title>My Website</title>

</head>

<body>

    <h1>Hello World</h1>

</body>

</html>

3. Headings

HTML मा h1 देखि h6 सम्म heading हुन्छन्। h1 सबैभन्दा मुख्य heading हो। 

<h1>Main Heading</h1>

<h2>Sub Heading</h2>

<h3>Section Heading</h3>

<h4>Heading Four</h4>

<h5>Heading Five</h5>

<h6>Heading Six</h6>

4. Paragraph

Paragraph लेख्न p tag प्रयोग गरिन्छ। 

<p>
This is my first paragraph.
</p>

5. Text Formatting

Text लाई विभिन्न तरिकाले format गर्न सकिन्छ। 

<b>Bold Text</b>

<strong>Important Text</strong>

<i>Italic Text</i>

<em>Emphasized Text</em>

<u>Underlined Text</u>

<mark>Highlighted Text</mark>

<small>Small Text</small>

<del>Deleted Text</del>

<sup>Superscript</sup>

<sub>Subscript</sub>

6. Links

<a href="https://example.com">
Visit Website
</a>

New Tab

<a
    href="https://example.com"
    target="_blank"
>
Open Website
</a>

7. Images

Website मा image राख्न img tag प्रयोग हुन्छ। 

<img
    src="photo.jpg"
    alt="My Photo"
    width="500"
>
alt attribute image को description दिन प्रयोग गरिन्छ।

9. Tables

    </tr>

    <tr>
        <td>Ram</td>

    </tr>

13. Div & Span

div ले content लाई block container मा राख्न मद्दत गर्छ। span ले inline content लाई group गर्न प्रयोग हुन्छ। 

<div class="card">

    <h2>My Card</h2>

    <p>Card Content</p>

</div>

<p>
This is
<span>important</span>
text.
</p>

17. HTML Comments

Code मा note लेख्न comment प्रयोग गरिन्छ। Browser मा comment देखिँदैन। 

<!-- This is an HTML comment -->

18. Meta Tags

Meta tags ले browser र search engines लाई webpage बारे information दिन्छ। 

<meta charset="UTF-8">

<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
>

<meta
    name="description"
    content="HTML Complete Course"
>

19. HTML Entities

Special characters लेख्न HTML entities प्रयोग गर्न सकिन्छ। 

&copy;   = ©

&reg;    = ®

&amp;    = &

&lt;     = <

&gt;     = >

20. iframe

अर्को webpage वा supported content लाई webpage भित्र embed गर्न iframe प्रयोग हुन्छ। 

<iframe
    src="https://example.com"
    width="600"
    height="400"
>
</iframe>

21. Accessibility

Website सबै user का लागि सजिलो बनाउन accessibility महत्त्वपूर्ण हुन्छ। 

<label for="email">
Email Address
</label>

<input
    id="email"
    type="email"
    aria-label="Email Address"
>
Images मा राम्रो alt text राख्नुहोस्। Forms मा labels प्रयोग गर्नुहोस्। Heading लाई सही क्रमले प्रयोग गर्नुहोस्।

25. Final HTML Project

अब सिकेका HTML concepts प्रयोग गरेर एउटा simple website बनाऔँ। 

<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>
        My Website
    </title>

</head>

<body>

    <header>

        <h1>
            My Website
        </h1>

        <nav>

            <a href="#home">
                Home
            </a>

            <a href="#about">
                About
            </a>

            <a href="#contact">
                Contact
            </a>

        </nav>

    </header>


    <main>

        <section id="home">

            <h2>
                Welcome
            </h2>

            <p>
                Welcome to my website.
            </p>

        </section>


        <section id="about">

            <h2>
                About
            </h2>

            <p>
                I am learning HTML.
            </p>

        </section>


        <section id="contact">

            <h2>
                Contact
            </h2>

            <form>

                <input
                    type="text"
                    placeholder="Your Name"
                >

                <input
                    type="email"
                    placeholder="Your Email"
                >

                <button type="submit">
                    Send
                </button>

            </form>

        </section>

    </main>


    <footer>

        <p>
            © 2026 My Website
        </p>

    </footer>

</body>

</html>
